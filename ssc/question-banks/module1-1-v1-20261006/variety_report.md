# Task-variety and coverage review

## MCQ bank

The bank has 40 unique normalized stems and no exact duplicate stems. It covers seven source-backed objectives. Observed operation families include classifying problem types; explaining ordered instructions; identifying lifecycle stages; mapping inputs, processing, and outputs; diagnosing algorithm properties; applying sequence formulas; tracing a selection; choosing a loop; identifying loop components; tracing counters, factorials, and sentinels; using `%` and `//`; and comparing efficiency/generalization.

### Repetition signals

- `ALGO-012`–`ALGO-016` all diagnose one algorithm property from a short example. They cover five distinct properties, but the response operation and stem pattern repeat.
- `ALGO-024`, `ALGO-026`, and `ALGO-027` all trace largest-so-far selection, varying list length or a tie case. This is procedural practice rather than three unrelated task families.
- `ALGO-035` and `ALGO-036` use the same sentinel sequence. One asks for the sum; the other asks why the sentinel is excluded. The answer targets differ, but the evidence and context repeat.
- `ALGO-037` and `ALGO-038` use the same digit-reversal example to test `%` and `//` separately. These are distinct operations but closely paired.

The loop objective has the largest allocation (11/40), justified by the lesson’s several worked loop designs. No one repeated operation dominates the entire bank. The lesson’s name-origin note and broad “hard versus easy algorithms” examples are not tested; these were treated as lower-priority facts for this introductory practice set rather than required coverage.

## Structured-response bank and cross-format overlap

The eight prompts use four response families: design/pseudocode, trace tables, debugging, and justified comparison. They are intentionally more demanding than selecting an answer. The general maximum task, sentinel design, factorial trace, sentinel debugging, and algorithm comparison reinforce concepts also represented in MCQs. `ALGO-E03` adds a triangle-area algorithm design; `ALGO-E06` asks students to diagnose an accumulator-initialization error; `ALGO-E05` integrates both digit operations in a full trace.

This is useful if the bank is meant to support scaffolded practice across response formats. If all formats appear together in one practice set, expect repetition around maxima, loops, and sentinels. A later expansion could add source-supported tasks on interpreting or refining the program-development stages, or on choosing between algorithm qualities in a concrete scenario.

## Coverage conclusion

No answerable task in the agreed source scope is wholly absent. Coverage is strongest for algorithm construction and tracing and lighter for testing/debugging as a development stage, algorithm-design documentation, and rationale for algorithm choice. Treat this report as an editorial review signal, not a mechanical quality score.
