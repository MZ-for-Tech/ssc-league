# Introduction to programming pilot

This pilot contains 40 MCQs and 8 structured-response questions, each worth 5 marks. It is based primarily on `ssc/Module 1/4. Module 1_4_Intr to programming.pdf`, with `ssc/Module 1/intro.md` as the text/code companion. The older `Module 1_3` PDF is recorded as a near-duplicate.

## Files

- `final_items.jsonl`, `essay_items.jsonl`: answer-bearing draft items.
- `blind_mcq_review.jsonl`, `blind_essay_review.jsonl`: question-only review packets with objectives, operations, and keys hidden.
- `item_review.jsonl`, `essay_review.jsonl`: review dispositions, answer/source audit notes.
- `lesson_plan.json`, `essay_plan.json`: source and coverage plans.
- `question_preview.html`: human-readable preview; code stimuli appear in actual code blocks.
- `mechanical_audit.json`, `review.md`, `essay_review.md`, `variety_report.md`: audit record.

Review is same-session AI review and should be treated as a careful pilot audit, not independent instructor or human validation.

All eight essays include an explicit answer justification, model answer, and five-point rubric.

## Bloom’s taxonomy

Every MCQ and structured response has a provisional operation-based Bloom level and rationale in the item JSONL and `bloom_review_full.json`. Labels describe the highest cognitive process needed; no level quotas are imposed. This same-session AI classification has not received independent review.
