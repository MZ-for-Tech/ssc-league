# Module 2 Lecture 2_1 pilot

Contains 40 MCQs and 8 structured-response questions worth 5 marks each. Sources: `ssc/Module 2/5. Module 2_1_Conditioning.pdf` and `ssc/Module 2/1_variables_and_operators.md`; `ssc/Module 2/2_making_decisions.md` was used to cross-check the conditional content also present in the PDF.

- `final_items.jsonl`, `essay_items.jsonl`: answer-bearing draft items.
- `blind_mcq_review.jsonl`, `blind_essay_review.jsonl`: metadata-hidden question packets; `blind_review_findings.jsonl` records per-item findings.
- `item_review.jsonl`, `essay_review.jsonl`: answer/source and rubric review notes.
- `lesson_plan.json`, `essay_plan.json`: source and coverage plan.
- `question_preview.html`: rendered preview, including code stimuli.
- `mechanical_audit.json`, `review.md`, `essay_review.md`, `variety_report.md`, `bloom_review.json`: review records.

Review was completed in the same AI session; earlier exposure to answer-bearing drafts means it is not independent or fully blind review.

All eight essays include an explicit answer justification, model answer, and five-point rubric.

## Bloom’s taxonomy

Every MCQ and structured response has a provisional operation-based Bloom level and rationale in the item JSONL and `bloom_review_full.json`. Labels describe the highest cognitive process needed; no level quotas are imposed. This same-session AI classification has not received independent review.
