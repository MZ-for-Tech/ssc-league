# Module 3 Lesson 5 — Titanic case study

Contains 40 MCQs and 8 structured responses worth 5 marks each. The package pairs `ssc/Module 3/5_titanic.md` with the corresponding PDF pages 60–68. It includes the source CSV, ten figures rendered as SVG with pandas/Matplotlib, and a preview that embeds the figures in the questions.

- `final_items.jsonl`, `essay_items.jsonl`: answer-bearing items with explanations, justifications, and rubrics.
- `question_preview.html`: visual questions with the actual plotted figures.
- `charts/manifest.json`: renderer for every chart asset.
- `variety_report.md`: visual and task coverage.
- `source_data/titanic.csv`, `dataset_source.md`: reproducible data input and provenance.
- `blind_mcq_review.jsonl`, `blind_essay_review.jsonl`: question-only packets for independent review; no independent blind review is claimed.
- `mechanical_audit.json`, `review.md`, `essay_review.md`, `source_review.md`, and plans: audit and source scope.

Data-dependent figures and keys use the lesson's exact cleaning sequence. Later results describe only the 670-row cleaned sample unless a question or chart explicitly says otherwise.
