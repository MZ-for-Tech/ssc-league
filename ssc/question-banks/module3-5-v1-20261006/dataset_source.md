# Dataset source

`source_data/titanic.csv` is the 891-row, 15-column Titanic sample used by Seaborn's `load_dataset('titanic')`, retrieved from the Seaborn example-data repository on 2026-10-06. The lesson's Markdown accesses its course-hosted CSV; its PDF explicitly loads the sample through Seaborn.

Upstream: https://github.com/mwaskom/seaborn-data/blob/master/titanic.csv
Raw file: https://raw.githubusercontent.com/mwaskom/seaborn-data/master/titanic.csv

All rates in this question bank are recomputed from the supplied source CSV using the lesson's selected fields and cleaning sequence.
