# Visual and task variety

The package contains ten distinct SVG figures generated from the lesson's Titanic sample: a cleaning-flow bar chart, age histogram, age–fare scatter plot, passenger-class counts, survival proportions by sex and class, fare box plot, sex/class interaction rates, missing-age shares by class, and sex/class group counts. Every figure uses pandas plotting backed by Matplotlib, matching the plotting approach shown in the lesson. The preview attaches each visual to the questions that need it; alt text describes the data and sample scope.

Tasks cover code reading, dataset inspection, cleaning counts and risks, numerical/categorical summaries, row-normalized crosstabs, visual interpretation, subgroup denominators, and qualified reporting.
